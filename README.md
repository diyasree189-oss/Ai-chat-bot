# 🤖 AI Chatbot

A simple AI-style chatbot web project built using **HTML, CSS and JavaScript**.

## Features

- Clean chatbot interface
- User and bot message bubbles
- Simple automated responses
- Clear chat button
- Responsive design for mobile and desktop
- No external libraries required

## Project Files

- `index.html` — Structure of the chatbot
- `style.css` — Styling and responsive layout
- `script.js` — Chat functionality and bot responses
- `README.md` — Project documentation

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Type a message in the input box.
4. Click **Send**.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Future Improvements

This demo can be connected to a real AI API in the future to generate more advanced responses.
